# Third-party code in the camera driver

StreamLens Camera is built from [softcam](https://github.com/tshino/softcam) v1.8.1 by tshino
(MIT licence, see `LICENSE-softcam`), renamed and given its own camera ID and shared-memory names.

`baseclasses/` are Microsoft's DirectShow base classes as shipped with softcam (MIT licence, from
Microsoft's Windows classic samples).
